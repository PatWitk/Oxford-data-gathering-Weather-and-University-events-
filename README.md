This code gathers data on Oxford weather and events. Weather for the next 7 days is gathered using a Meteo free access API (https://open-meteo.com/) and upcoming events are scraped from Oxford University events page (https://events.ox.ac.uk/events?tab=nextweek&r=1783956389557).
This data is exported as two seperate CSVs and used in PowerBI to make the following visualisation, allowing for planning of the week ahead with events and temperature in mind.

(The 'Events per day and peak temperature' visual is done to show a PowerBi relationship between two seperate tables)
